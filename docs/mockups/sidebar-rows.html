Sidebar rows — four ways to fit Git + agent status

Drawn at the app's real numbers: ChromeTheme derived from Afterglow, rows inset 6 pt, index column at 14 pt, name at 12 pt, second line at 10.5 pt mono. Drag the slider — the default sidebar is only 168 pt wide, which is the whole design problem: at that width the second line holds roughly 20 characters.

168 pt (default) range in AppSettings: 120–400

What each mark means

MarkMeaningWhere the value comes from
spinner Agent is working tmux pane option @agent_state=working
amber, breathing Agent is blocked on you — permission or a question @agent_state=needs-input
green Agent finished its turn (fades after a few minutes) @agent_state=done
main Current branch, truncated from the left when long git status --porcelain=v2 --branch
+3 ~1 3 staged / added, 1 modified but unstaged same call, one pass
↑2 ↓1 2 commits to push, 1 to pull — against the last fetch, not the network # branch.ab line
✓ Clean tree no entries in the porcelain output
