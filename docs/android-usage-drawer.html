用量放在对话页侧边栏的最下面（第四版）

位置和交互照 Mac，样子照安卓的侧边栏。点标题打开侧边栏，或者从屏幕左边缘往右拖；点侧边栏外面关上；agent 列表可以滚动；点最下面的用量区可以展开和收起。

用量区和 agent 列表之间怎么分开（点一下切换）

    对话页的侧边栏：
  上面：agent 列表，和现在一模一样，可以滚动
  最下面：用量区，固定在侧边栏底部，不跟着 agent 列表滚动
    和 agent 列表之间怎么分开：见上面几种样式，你选一种
    默认（收起）：每家一行，有几家显示几行，每一行只显示这一家的周用量
      例如：● Claude  Weekly      30% · 3d 8h
            ● Gemini  Weekly       5% · 5d 13h
            ● Grok    Weekly     100% · 1d 14h
      每一行下面一根进度条：有颜色的部分是用掉的，接着是灰色的部分，中间不断开；
      在这一周的时间走到的位置，把整根条断开一个小口（代替原来的竖线）
      某一家在这台主机上从来没查到过数据：不显示这一行
    如果点了用量区：
      往上展开，顶上出现「Usage」小标题和收起箭头
      每家一个小标题（圆点 + 名字 + 套餐），下面列出这一家的全部窗口
      agent 列表能看到的区域变短，列表本身不动，还能滚动
      窗口太多时，用量区自己可以滚动
    如果展开着再点「Usage」那一行：收起，回到每家一行

进入聊天模式后的第一页（agent 列表页）：
  把上次加的底部用量条去掉，那里什么都不放

    用量数字是这台 MacBook 现在的真实数据，倒计时按真实时间走；agent 列表和对话内容是照你的截图编的。
